# Bound-GBM-CIR-MonteCarlo

This directory extends the bounded SDE/lattice-validation experiments by running multiple stochastic paths and recording aggregate statistics.

## What it does

- simulates multiple trajectories under different stochastic regimes
- transforms each step into a discrete arithmetic state
- applies lattice acceptance criteria
- records pass/fail rates, phase summaries, and bound statistics

## Typical models included

- Geometric Brownian Motion (GBM)
- Cox-Ingersoll-Ross (CIR)
- pure random walk / driftless diffusion variants

## Build

```bash
g++ -std=c++17 -O3 -march=native main.cpp -o sde_engine -lpthread
```

## Run

```bash
./sde_engine
```

## Output

The executable writes structured results to the terminal and/or output files generated by the current implementation.

## Scope

This project is best understood as a research prototype focused on the interaction between stochastic dynamics and arithmetic lattice filtering.
