# 4D Number-Theoretic Random Walk & Spectral Interrogation Engine

This version is a later prototype in the historical chain of the project. It explores 4D number-theoretic walk dynamics in combination with spectral probing and drift analysis.

## Overview

The code in this folder is designed to test:

- prime-based coordinate generation
- 4D random-walk or lattice-walk behavior
- spectral or zero-based interrogation of path structure
- performance and empirical drift observations

## Build

```bash
g++ -O3 main.cpp -o walk_engine
```

## Run

```bash
./walk_engine
```

## Scope

This is an experimental engineering artifact aimed at testing ideas, collecting empirical behavior, and comparing model variants. It is not a finished library interface or a broad application package.
