# Bound-GBM-CIR

This folder contains a small stochastic simulation project that evaluates Geometric Brownian Motion (GBM) and Cox-Ingersoll-Ross (CIR) paths, then filters the resulting points through a discrete arithmetic lattice.

## Purpose

The program models continuous-time SDE paths and checks whether the discretized state values satisfy number-theoretic constraints based on sum-of-two-squares representations. This is used as a lightweight lattice-validation and phase/bound analysis experiment.

## Core ideas

- `GBM` model: multiplicative diffusion with drift
- `CIR` model: mean-reverting square-root diffusion
- lattice gate: check whether a scalar can be represented as a sum of two squares
- phase and bound tracking: compute derived metrics for each accepted node

## Build

```bash
g++ -O3 -std=c++17 main.cpp -o sde_simulation -pthread
```

## Run

```bash
./sde_simulation
```

## Notes

This is a focused experiments directory rather than a production numerical library. The exact output format and metrics are generated by the source code in this folder.
