# The Asymptotic Riemann-Hyperspace Project

This subdirectory contains a native C++ implementation of the hyperspace prototype. It is a compact experimental engine for exploring higher-dimensional prime-coordinate mappings and phase-driven path behavior.

## Quick start

```bash
mkdir build && cd build
cmake ..
make
./RiemannHyperspaceEngine
```

## Purpose

The code is intended to test how prime arithmetic, geometric decomposition, and structured phase modulation interact in a higher-dimensional setting.

## Notes

- This project is experimental and research-oriented.
- It may include multiple prototype versions and generated output files.
- The source should be treated as a working model rather than a finalized product API.
